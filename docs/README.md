# Engineering documentation

Read these in order if you are new to the project:

1. [Project explained](PROJECT_EXPLAINED.md) - the electrical-engineering ideas and a short interview walkthrough.
2. [Architecture](ARCHITECTURE.md) - how the scripts and study artifacts fit together.
3. [Data dictionary](DATA_DICTIONARY.md) - units, flags, IDs, and meanings of blank results.
4. [Study procedure](STUDY_PROCEDURE.md) - how to run, review, and retain the analysis.
5. [Measured results](RESULTS.md) - findings, model evaluation, and limits of the conclusions.

The project is an educational planning study on a standard test case. Its outputs are traceable simulation evidence. They are not utility-approved operating instructions, field drawings, or a NERC compliance determination.
